# API REST Clientes

Proyecto desarrollado con Node.js, Express y MySQL.

## Funcionalidades

- Obtener clientes
- Crear clientes
- Actualizar clientes
- Eliminar clientes
- Manejo de errores HTTP
- Validación de correo duplicado

## Tecnologías utilizadas

- Node.js
- Express
- MySQL
- Postman

## Instalación

### Clonar repositorio

```bash
git clone https://github.com/diegodejota/Semana-9-Plataforma-Web-.git
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar servidor

```bash
npm start
```

## Pruebas

Las pruebas de los endpoints fueron realizadas utilizando Postman.

## Endpoints

### Obtener clientes

GET /clientes

### Crear cliente

POST /clientes

### Actualizar cliente

PUT /clientes/:id

### Eliminar cliente

DELETE /clientes/:id
